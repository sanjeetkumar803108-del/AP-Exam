Question 7: Odd and Even Binary Numbers
★★★★ HIGH PRIORITY
Correct Answer: (C) — Examine the rightmost bit (least significant bit): if it is 1, the number is odd; if it is 0, the number is even.

- Lossless RLE shrinks repetitive night-time readings without losing a single fraction of a degree upon decompression.
• (d) Metadata Header vs. Payload in Satellite Telemetry:
- Payload: The compressed temperature readings representing the actual ocean measurements collected by the buoy.
- Metadata Header: The 32-byte contextual data packet containing the buoy's identity ID, GPS coordinates, timestamp, and battery voltage.
- Station Processing: The satellite receiving station uses the metadata to confirm the buoy's location, verify battery health, and catalog the observation time, and uses the payload to decompress and plot the temperature time series into the scientific climate database.

Essential Unit 2 Data Representation Reference Framework
Core powers of 2 table, hexadecimal equivalents, sampling equations, compression taxonomies, and metadata definitions.
  • Powers of 2 and Bit Representation:
    • 2⁰=1, 2¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32, 2⁶=64, 2⁷=128, 2⁸=256, 2⁹=512, 2¹⁰=1024, 2¹⁶=65,536, 2³²=4,294,967,296.
    • An unsigned sequence of n bits can represent exactly 2ⁿ distinct values, ranging from 0 to 2ⁿ − 1.
    • Every additional bit doubles the total quantity of distinct representable values.
  • Hexadecimal (Base-16) & Text Encoding:
    • Digits: 0–9 and A (10), B (11), C (12), D (13), E (14), F (15). Exactly 4 bits (1 nibble) map to 1 hex digit. 2 hex digits = 1 byte (8 bits).
    • 24-bit RGB Color: #RRGGBB (Red, Green, Blue each 00₁₆ to FF₁₆, decimal 0 to 255).
    • ASCII: 7-bit standard (128 characters). Unicode (UTF-8/UTF-16): universal standard supporting >1.1 million characters, international languages, and emojis.
  • Integer Overflow vs. Floating-Point Round-Off:
    • Integer Overflow: Occurs when an integer calculation yields a value too large for the allocated fixed-width bits, causing rollover/wraparound (e.g., 8-bit unsigned 255 + 1 = 0).
    • Floating-Point Round-Off: Occurs because non-terminating fractional real numbers (like 0.1 and 0.2) cannot be represented with infinite precision in finite binary bits, creating tiny precision discrepancies.
  • Analog vs. Digital & Audio Sampling:
    • Analog is continuous; Digital is discrete (sampled approximations represented in binary).
    • Sampling Rate (Hz): Number of samples measured per second. Bit Depth: Number of bits per sample (quantization resolution).
    • Audio Size (bits) = Sample Rate (Hz) × Bit Depth (bits) × Channels × Time (seconds).
  • Data Compression & Metadata:
    • Lossless Compression (ZIP, PNG, FLAC, RLE, LZW): 100% reversible bit-for-bit without data loss. Required for code, text, and financial/medical data.
    • Lossy Compression (JPEG, MP3, MP4): Permanently discards imperceptible or redundant data based on human psychovisuals/psychoacoustics. High compression ratios (10:1 to 20:1), but irreversible.
    • Metadata: Data about data (timestamps, GPS, file size, author). Changing metadata does not alter primary content. Poses significant privacy risks if not scrubbed.
