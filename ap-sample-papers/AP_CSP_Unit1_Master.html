Essential Unit 1 Creative Development Reference Framework
Core AP exam pseudocode conventions, defect classifications, development methodologies, and licensing taxonomies.
  • AP CSP Pseudocode Conventions: a <- expression evaluates expression and assigns to variable a. DISPLAY(expression) displays value followed by a space. INPUT() accepts user input. 1-based indexing is standard for lists on the AP exam: aList[1] accesses the first element.
  • Defect Typologies:
    • Syntax Error: Violates grammatical structure of the language; detected before execution; prevents running.
    • Runtime Error: Occurs during execution, causing the program to abnormally crash or terminate (e.g., division by zero, null pointer, index out of bounds).
    • Logic Error: Program compiles and runs without crashing, but computes or displays the wrong result due to flawed algorithm design.
    • Overflow Error: Occurs when a calculated integer exceeds the maximum finite bit representation limit.
    • Round-off Error: Occurs when fractional real numbers cannot be represented with exact precision in binary floating point.
  • Program Purpose vs. Function:
    • Purpose: The problem being solved or the value provided to users (e.g., helping athletes maintain hydration).
    • Function: How the code operates algorithmically (e.g., reading numeric text inputs, validating formats, converting units, updating UI controls).
  • Development Methodologies:
    • Iterative Development: Repeating cycles of investigation, design, coding, testing, and feedback.
    • Incremental Development: Building the system piece by piece in small, manageable, fully functional modules.
    • Pair Programming: Two programmers at one station; the driver writes code while the navigator reviews strategy, catches bugs, and plans architecture.
  • Intellectual Property & Licensing:
    • Copyright: Exclusive legal right protecting original works of authorship upon creation.
    • Creative Commons (CC): Public licenses enabling creators to grant standard copyright permissions.
    • CC BY: Requires attribution. CC BY-SA: Requires attribution and sharing alike. CC BY-NC: Commercial use forbidden.
    • Open Source (MIT / GPL): Free distribution of source code with permissive or copyleft requirements.
    • Public Domain: Works with expired or forfeited copyright; usable freely without permissions.
