APPENDIX FORMULA REFERENCE & THEOREMS
Essential Unit 10 Rules
Core convergence tests, Taylor and Maclaurin expansions, and error bound theorems required for AP Calculus BC.
  • Convergence Tests for Infinite Series: • nth-Term Test for Divergence: If lim_(n→∞) a_n ≠ 0 (or does not exist), ∑ a_n diverges. If lim a_n = 0, the test is strictly inconclusive! • Geometric Series: ∑_(n=0)^∞ a rⁿ = a / (1 − r) if |r| < 1. Diverges if |r| ≥ 1. • p-Series Test: ∑ 1 / n^p converges if p > 1; diverges if p ≤ 1 (Harmonic series when p = 1). • Integral Test: If f(x) is continuous, positive, and decreasing on [1, ∞), ∑_(n=1)^∞ f(n) and ∫₁^∞ f(x) dx share the same convergence behavior. Remainder: R_N ≤ ∫_N^∞ f(x) dx. • Direct Comparison Test (DCT): If 0 ≤ a_n ≤ b_n and ∑ b_n converges ⟹ ∑ a_n converges. If a_n ≥ c_n ≥ 0 and ∑ c_n diverges ⟹ ∑ a_n diverges. • Limit Comparison Test (LCT): If lim_(n→∞) (a_n / b_n) = L with 0 < L < ∞, then both series share the exact same convergence behavior. • Alternating Series Test (AST): ∑ (−1)ⁿ⁺¹ b_n converges if b_n > 0, b_(n+1) ≤ b_n, and lim_(n→∞) b_n = 0. • Alternating Series Error Bound: |S − S_N| ≤ b_(N+1) (error is bounded by the magnitude of the first omitted term). • Ratio Test: L = lim_(n→∞) |a_(n+1) / a_n|. Converges absolutely if L < 1; diverges if L > 1; inconclusive if L = 1.
  • Taylor and Maclaurin Series: • Taylor Polynomial Centered at c: P_n(x) = ∑_(k=0)^n [ f^(k)(c) / k! ] (x − c)^k. • Maclaurin Polynomial (c = 0): P_n(x) = ∑_(k=0)^n [ f^(k)(0) / k! ] x^k. • Taylor Series Coefficients: a_k = f^(k)(c) / k! ⟹ f^(k)(c) = k! · a_k.
  • Common Maclaurin Series to Memorize: • 1 / (1 − x) = ∑_(n=0)^∞ xⁿ = 1 + x + x² + x³ + ... for |x| < 1. • eˣ = ∑_(n=0)^∞ xⁿ / n! = 1 + x + x²/2! + x³/3! + ... for (−∞, ∞). • sin x = ∑_(n=0)^∞ [ (−1)ⁿ x^(2n+1) ] / (2n + 1)! = x − x³/3! + x⁵/5! − ... for (−∞, ∞). • cos x = ∑_(n=0)^∞ [ (−1)ⁿ x^(2n) ] / (2n)! = 1 − x²/2! + x⁴/4! − ... for (−∞, ∞). • ln(1 + x) = ∑_(n=1)^∞ [ (−1)ⁿ⁻¹ xⁿ ] / n = x − x²/2 + x³/3 − ... for (−1, 1]. • arctan x = ∑_(n=0)^∞ [ (−1)ⁿ x^(2n+1) ] / (2n + 1) = x − x³/3 + x⁵/5 − ... for [−1, 1].
  • Lagrange Error Bound (Taylor's Theorem Remainder): • |R_n(x)| = |f(x) − P_n(x)| ≤ [ M / (n + 1)! ] |x − c|^(n+1), where M = max |f^(n+1)(t)| for t between c and x.
