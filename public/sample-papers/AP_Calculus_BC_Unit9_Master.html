APPENDIX FORMULA REFERENCE & THEOREMS
Essential Unit 9 Rules
Core formulas, parametric derivatives, polar area theorems, and vector kinematics required for AP Calculus BC.
  • Parametric Derivatives & Tangent Slopes: • First Derivative: dy/dx = (dy/dt) / (dx/dt) provided dx/dt ≠ 0. • Horizontal Tangent: dy/dt = 0 and dx/dt ≠ 0. Vertical Tangent: dx/dt = 0 and dy/dt ≠ 0. • Second Derivative: d²y/dx² = [ d/dt(dy/dx) ] / [ dx/dt ]. Never divide d²y/dt² by d²x/dt²!
  • Parametric Arc Length & Planar Distance: • Total Distance Traveled = ∫_t₁^t₂ √[ (x'(t))² + (y'(t))² ] dt = ∫_t₁^t₂ ||v(t)|| dt.
  • Vector-Valued Functions & Planar Kinematics: • Position: r(t) = ⟨ x(t), y(t) ⟩. Velocity: v(t) = r'(t) = ⟨ x'(t), y'(t) ⟩. Acceleration: a(t) = v'(t) = ⟨ x''(t), y''(t) ⟩. • Speed: ||v(t)|| = √[ (x'(t))² + (y'(t))² ]. Direction Angle: tan θ = y'(t) / x'(t). • Rate of Change of Speed: d/dt ||v(t)|| = [ v(t) · a(t) ] / ||v(t)|| = [ x'x'' + y'y'' ] / √[ (x')² + (y')² ]. • Speed is increasing when v · a > 0; decreasing when v · a < 0. Particle is at rest when v(t) = ⟨ 0, 0 ⟩.
  • Polar Coordinates & Conversions: • Coordinate relations: x = r cos θ, y = r sin θ, r² = x² + y², tan θ = y / x. • Slope of Polar Tangent Line: dy/dx = (dy/dθ) / (dx/dθ) = [ (dr/dθ) sin θ + r cos θ ] / [ (dr/dθ) cos θ − r sin θ ]. • Tangents at the Pole: If r(θ₀) = 0 and r'(θ₀) ≠ 0, the line tangent to the curve at the pole is θ = θ₀.
  • Area of Polar Regions: • Single Polar Curve: Area = (1 / 2) ∫_α^β [r(θ)]² dθ. • Area Between Two Polar Curves: Area = (1 / 2) ∫_α^β [ (R(θ))² − (r(θ))² ] dθ, where R(θ) is outer radius and r(θ) is inner radius. • Rate of Change of Swept Area: dA/dθ = (1 / 2)[r(θ)]² and dA/dt = (1 / 2)[r(θ)]² (dθ/dt).
  • Length of a Polar Curve (Polar Arc Length): • Arc Length L = ∫_α^β √[ [r(θ)]² + [dr/dθ]² ] dθ.
