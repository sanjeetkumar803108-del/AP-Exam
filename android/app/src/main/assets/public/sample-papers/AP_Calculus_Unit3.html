Essential Unit 3 Rules

Core formulas required for mastery of composite, implicit, and inverse differentiation.

  • Chain Rule: d/dx [f(g(x))] = f′(g(x))·g′(x).
  • Common chain forms: d/dx [e^u] = e^u·u′  |  d/dx [ln u] = u′/u  |  d/dx [uⁿ] = n·u^(n−1)·u′.
  • Trig chain forms: d/dx [sin u] = cos u·u′  |  d/dx [tan u] = sec²u·u′  |  d/dx [sec u] = sec u tan u·u′.
  • Implicit Differentiation: Differentiate both sides with respect to x, attaching dy/dx to every y-term, then solve for dy/dx.
  • Horizontal tangent: numerator of dy/dx is 0. Vertical tangent: denominator of dy/dx is 0 (numerator nonzero).
  • Inverse Function Derivative: (f⁻¹)′(b) = 1 / f′(f⁻¹(b)). First find the input a with f(a) = b, then take 1/f′(a).
  • Inverse Trig: (arcsin u)′ = u′/√(1 − u²)  |  (arccos u)′ = −u′/√(1 − u²)  |  (arctan u)′ = u′/(1 + u²).
  • Higher-Order: f″ = derivative of f′. For motion, v(t) = s′(t) and a(t) = v′(t) = s″(t).
  • Speed test: speed increases when v and a have the same sign; it decreases when their signs differ.
