Essential Unit 5 Formulas and Theorems
  • Mean Value Theorem (MVT): If f is continuous on [a, b] and differentiable on (a, b), there exists at least one c in (a, b) such that f′(c) = [f(b) − f(a)] / (b − a).
  • Rolle's Theorem: If in addition f(a) = f(b), then f′(c) = 0 for some c in (a, b).
  • Extreme Value Theorem (EVT): A continuous function on a closed bounded interval [a, b] attains both an absolute maximum and an absolute minimum on [a, b].
  • Critical Numbers: Values c in the domain of f where f′(c) = 0 or f′(c) does not exist.
  • First Derivative Test: If f′ changes from + to − at c, f has a local maximum; if f′ changes from − to +, f has a local minimum. If f′ does not change sign, there is no local extremum.
  • Candidates Test for Absolute Extrema: Evaluate f at all domain endpoints and all interior critical numbers. The largest value is the absolute maximum; the smallest is the absolute minimum.
  • Concavity & Points of Inflection: f″(x) > 0 implies concave up; f″(x) < 0 implies concave down. An inflection point requires an actual sign change of f″(x).
  • Second Derivative Test: If f′(c) = 0 and f″(c) > 0, f has a local minimum at c. If f′(c) = 0 and f″(c) < 0, f has a local maximum. If f″(c) = 0, the test is inconclusive.
  • Optimization Strategy: 1) Identify objective function and constraint; 2) Express objective in terms of a single variable; 3) State feasible domain; 4) Find critical points and justify global extremum using derivative tests or endpoints.
